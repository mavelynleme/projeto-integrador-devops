# Checklist de Avaliação

| Critério | Status | Arquivos de evidência | Comandos sugeridos para demonstração | Observações |
| --- | --- | --- | --- | --- |
| Git/Git Flow | Parcial | Histórico Git, branches remotas como `develop` e `feature/*`, triggers em `.github/workflows/ci.yaml` para `develop`, `master` e `main` | `git branch -a`; `git log --oneline --graph --decorate -n 10` | Continuar usando branches de feature e Pull Requests para `develop`. |
| Sistemas Operacionais Linux | Parcial, aprimorado | `scripts/monitor-system.sh`, `scripts/backup.sh`, `scripts/cleanup-logs.sh`, `scripts/install-cron.sh`, `logs/.gitkeep`, `backups/.gitkeep` | `bash -n scripts/*.sh`; `./scripts/monitor-system.sh`; `tail -n 50 logs/system-monitor.log` | A execução dos scripts requer Linux, WSL ou Git Bash. Cron requer `crontab`. |
| Pipeline CI/CD | Implementado para validação | `.github/workflows/ci.yaml` | Abrir um PR para `develop`; inspecionar a execução no GitHub Actions | O CI instala dependências, executa lint, testes, valida sintaxe shell, gera o build da aplicação e valida o build Docker. Ele não faz deploy. |
| Docker | Implementado para evidência de build/runtime | `Dockerfile`, `docker-compose.yml`, `.dockerignore` | `docker build -t linux-devops-dashboard .`; `docker compose up --build` | A validação local requer Docker Desktop, Docker Engine ou equivalente. O CI valida o build Docker no Ubuntu. |
| Kubernetes | Parcial, aprimorado | `k8s/deployment.yaml`, `k8s/service.yaml`, `k8s/configmap.yaml`, `k8s/secret.example.yaml` | `kubectl apply -f k8s/`; `kubectl get pods`; `kubectl get svc`; `kubectl port-forward svc/linux-devops-dashboard 8080:80` | Requer `kubectl` e um cluster, como Docker Desktop Kubernetes, Minikube, Kind ou cluster remoto. |
| Testes Automatizados | Implementado para evidências centrais | `vitest.config.ts`, `src/test/setup.ts`, `src/test/app-render.test.tsx`, `src/test/devops-evidence.test.ts`, `.github/workflows/ci.yaml` | `npm run test` | Os testes validam a renderização da aplicação, textos visíveis do dashboard, renderização do botão de tema e arquivos de evidência DevOps. |
| Logs e Monitoramento | Parcial, aprimorado | `scripts/monitor-system.sh`, `scripts/cleanup-logs.sh`, `logs/.gitkeep`, `.gitignore` | `./scripts/monitor-system.sh`; `ls -la logs`; `tail -n 50 logs/system-monitor.log` | Arquivos `.log` gerados são ignorados intencionalmente e não devem ser commitados. |
| Gerenciamento de Configuração | Parcial | `.env.example`, `k8s/configmap.yaml`, `k8s/secret.example.yaml` | `cat .env.example`; `kubectl apply -f k8s/configmap.yaml` | `.env.example` é documentação. O arquivo de Secret é apenas exemplo e contém placeholders. |
| Organização e Documentação | Implementado para apresentação | `README.md`, `docs/evaluation-checklist.md`, `docs/presentation-script.md` | Abrir o README e os documentos durante a apresentação | A documentação descreve estado atual, comandos, limitações e melhorias futuras. |
